# 🥁 Drum Kit

An interactive Drum Kit web application built using **HTML**, **CSS**, and **JavaScript**. Users can play different drum sounds either by clicking the on-screen drum buttons or by pressing the corresponding keys on the keyboard.

## 🚀 Features

- 🎵 Play drum sounds by clicking buttons
- ⌨️ Play drum sounds using keyboard keys
- ⚡ Instant audio response
- 🎨 Simple and responsive user interface
- 📱 Beginner-friendly DOM Manipulation project

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## 🎹 Supported Keys

| Key | Sound |
|-----|-------|
| W | Tom 1 |
| A | Tom 2 |
| S | Tom 3 |
| D | Tom 4 |
| J | Snare |
| K | Crash |
| L | Kick Bass |

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/drum-kit.git
```

2. Open the project folder.

3. Open **index.html** in your browser.

4. Click on any drum button or press the corresponding keyboard key to play sounds.
